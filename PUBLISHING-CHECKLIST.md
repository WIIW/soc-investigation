# Kontrola publikacji SOC BOTSv2

Stan: 17.11.2026. Repozytorium prywatne; publiczne udostępnienie pozostaje osobną decyzją. Szczegóły i ograniczenia: [raport kontroli](PUBLICATION-QA.md).

## Wykonane
- [x] Potwierdzić prywatność repozytorium i dostęp do zapisu.
- [x] Pobrać bezstratnie 12 oryginalnych Markdown i zapisać manifest SHA-256.
- [x] Zastąpić tymczasowy README pełnym README z pakietu i dodać linki do PDF.
- [x] Dołączyć 8 niezmienionych ilustracji; uzgodnić nazwy i sprawdzić SHA-256.
- [x] Sprawdzić odwołania względne, obrazy i lokalny render Markdown/Mermaid.
- [x] Doprecyzować podpisy RETR i STOR oraz oznaczenie rekonstrukcji wiadomości.
- [x] Przejrzeć teksty, obrazy i SVG pod kątem danych autora, sekretów i pełnych payloadów.
- [x] Podać źródło danych BOTSv2 i licencję CC0 1.0 we wstępie README.
- [x] Wygenerować trzy PDF A4 z podpisami i powiększeniami dowodów.
- [x] Wyrenderować i obejrzeć wszystkie strony, sprawdzić marginesy, tabele i odsyłacze.
- [x] Sprawdzić diagram na GitHubie - autor potwierdził poprawny wygląd.
- [x] Sprawdzić czytelność PDF na telefonie - potwierdzona przez autora.

## Otwarte
- [ ] Sprawdzić ilustracje i szerokie tabele w widoku GitHuba.
- [ ] Wykonać test 10 s / 2 min / 10 min z osobą z branży.
- [ ] Osobno zatwierdzić ewentualne udostępnienie publiczne.

Inicjalizację zachowano w historii: `0f54ead` i `402be5c`. Pakiet nie zawiera datasetu, próbek wykonywalnych ani pełnego dziennika roboczego. Zatwierdzone raporty i oryginalne załączniki Notion pozostają niezmienione.
